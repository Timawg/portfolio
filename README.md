# Tim Gunnarsson's portfolio

A personal site for Tim Gunnarsson, an iOS software engineer in Stockholm. The site covers his career and features Tellus, a world map and travel guide for iPhone and iPad.

To preview the site locally, serve the `dist` directory with Python 3.

```sh
python3 -m http.server 8000 --directory dist
```

Open [http://localhost:8000](http://localhost:8000). The site uses HTML, CSS, JavaScript, and SVG, so there are no dependencies to install or build commands to run.

GitHub Pages publishes the `dist` directory on every push to `main`. [Live portfolio](https://timawg.github.io/portfolio/)
